# Contributing

Thanks for helping improve agentic-reliability-patterns.

1. Open an issue describing the problem or improvement before large changes.
2. Keep examples small, reproducible, and vendor-neutral where possible.
3. Include tests and documentation for behavior changes.
4. Run `python -m unittest discover -s tests -v` before opening a pull request.
5. Never add access tokens, personal data, internal-company material, or proprietary APIs.

Be constructive in reviews. The project maintainer may decline features that broaden scope without clear utility.
